# calculations/

Handwritten calculations, as pasted in, next to what became of them.

One directory per calculation, `YYYY-MM-DD-<slug>/`, from `_template/`:

```
calculations/2026-08-28-gap-expansion/
  README.md        what it computes, symbols, assumptions, what it produced
  handwriting.png  the image, exactly as pasted
```

The LaTeX transcription does **not** live here — it goes into the lab book entry for the same
date, so that the mathematics and the code that came out of it are in one place. This directory
holds the original and the intake record.

## How one gets made

A photo is pasted into the chat. The agent saves the image, fills in `README.md`, transcribes the
mathematics faithfully into a new lab book entry, and writes the code from it. Only then does it
check the calculation, and if it finds something, it reports the step, the evidence and a proposed
fix — and records the decision in the entry. It never edits the mathematics itself.
