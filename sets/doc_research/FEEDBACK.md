# FEEDBACK

Things that did not work. The agent writes here by itself whenever something goes wrong for you —
you do not have to remember to report anything.

**This file never leaves your machine unless you send it.** When you have had enough of something,
send this file to Gabriel; it is written so that we can fix the instructions everyone gets, rather
than you working around them forever. Delete anything you do not want to share.

The difference between this and [TASTE.md](TASTE.md): taste is fixed here, immediately, by the
agent. Feedback is fixed by us, upstream.

## Entry format

    ### YYYY-MM-DD — one-line summary
    - **Doing:** what you were trying to get done
    - **Went wrong:** what happened instead
    - **You said:** "verbatim quote"
    - **Agent did:** how it was handled in the end
    - **Resolved:** yes / no / worked around
    - **Implicated:** the file or rule that should have covered this

Newest entries at the bottom. Nothing here is ever rewritten.
