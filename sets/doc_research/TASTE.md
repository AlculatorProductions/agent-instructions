# TASTE

Erin's rules for how the agent works. **These override [CLAUDE.md](CLAUDE.md).**

This file starts empty and fills up on its own. Say what you want in the chat — "shorter
messages", "stop explaining every equation step", "don't add a figure caption for quick throwaway
plots" — and the agent writes it down here, dated, and follows it from then on.

You can edit or delete any line yourself. A deleted line is genuinely forgotten.

If what you want is something the agent says it cannot do, that is a problem with the instructions
we shipped, not with you: it goes in [FEEDBACK.md](FEEDBACK.md) and comes back to us.
